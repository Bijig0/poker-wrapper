3 Table — which format to play, how much to bring, and who signs in

Attach to table
The tables open in the CoinPoker client right now — joined, you do not have to be seated. The wrapper reads the one you pick and no other, so a busier table can never take over the panel. Join a table in the client and it appears here within a few seconds.
Format
The strategy names the formats its layers were built for; the others are greyed out. Start opens the table window and the wrapper drives the lobby to this table. The badge on the panel warns when the open table is not this one. The format labels the session. You take the seat yourself in the CoinPoker client — the wrapper reads the table you attach above from the client's own log (every card, action and stack, exactly), and only that table. Presses go to the table window; auto-execute arms only on a Practice Games table.
Tables
How many tables this session opens. Each one is its own wrapper with its own window and its own answers, but they share ONE session, one login and one balance — you declare it here and the rest join. They tile the table screen between them; their answers all appear on this panel. Only 1, 2 and 4: the screen splits into halves or quarters, so three would cost every table the smaller window and leave a quarter empty.

4 Settings — the strategy decides what answers you get; these are the session's own knobs

Answers · set by the strategy
pick a strategy above
A strategy is the whole answer: which preflop layer, which postflop layer, which opponent model. Every source it uses becomes a required check below.
Table browser Wipes the table window's HTTP, script and service-worker caches (not cookies, not the sign-in) when the session starts, so the lobby loads fresh. Use it after a sluggish or half-loaded lobby.
Debug recording
Every tick's screenshot and parsed state, under this session's id. Needed for Replay Review.
Auto-execute picks
timing
Instant fires the moment the answer lands. Randomized waits a fresh 1.5–2 second draw before each pick — nothing is typed early, and a pick whose spot moves on during the wait is dropped, never played late.
no answer
For unattended runs. When a decision gets no answer — the solver gave up on it, your time is down to 4 s (the clock plus the time bank, which the client starts by itself when the clock reaches 0), the clock reaches the time-bank mark with Time bank set to Leave it, or 30 s pass with no readable clock — the wrapper checks if checking is free and otherwise folds, instead of letting the clock run out (a few timeouts sit you out). The same happens when there IS an answer but it is still held, or its press was refused and retried, with 4 s left (a refusal with no retry left does not spend the time bank). Each one is logged as a no-answer-fold session event with its reason, for the no-answer audit. Currently acts on real-money tables too.
CoinPoker: auto-execute arms only on a Practice Games table (the server marks those as play chips) unless the real-money box below is ticked too.
budget minutes hands
Whichever budget runs out first disarms it. Without this box a real-money table refuses to arm and the declaration waits for a practice table.
Plays each study pick on the table for you, with no keypress — the same relay the panel's action buttons use. This only sets how the panel OPENS; the toggle there turns it on and off during the session. Off arms nothing: you press Enter per decision, which is the assistive path and needs no declaration.
Time bank
Ring tables offer a +45s button once your clock reaches about 9 seconds, and start that time bank by themselves when your clock reaches 0. With this on, the wrapper also presses it once per decision, whether picks are pressed or auto-executed (the press has never been seen to change anything on screen before 0). It only buys time; it never chooses an action.
Top-up
Ring tables have no auto-rebuy of their own. With this on, whenever your stack is below the table's max buy-in the wrapper opens Buy chips between hands, takes the Max the client offers and presses BUY — the amount is always the client's own number. Off = you buy chips yourself.
Sat out
A few timed-out decisions and the table sits you out. With this on, the wrapper presses I AM BACK for you (after 2 s, up to 3 tries per sit-out), logged as a sit-back-in session event. It leaves you out while the connection guard has sat you out for a slow link. If you sit out on purpose, choose Stay out — it cannot tell your sit-out from the table's.
